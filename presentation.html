Noise Remover · Method 1

Moving Average Filter (Time-Domain Convolution)

🔧 How does it work?
1
Construct Uniform Kernel (N = 9)
Create impulse response h = [1/N, 1/N, ..., 1/N] with length 9.
2
Direct Convolution (x * h)
The kernel slides sample by sample: y[n] = (1/N) Σ x[n−k].
3
Low-Pass Smoothing Effect
High-frequency random noise cancels out, preserving smooth underlying tones without any Fourier transform.
y[n] = (1/N) ∑_{k=0}^{N-1} x[n - k] = (x * h)[n]
Pure Time-Domain LTI Filtering

def moving_average_filter(x, N=9): h = np.ones(N) / N # uniform kernel of length N return np.convolve(x, h, mode='same')

Noise Remover · Method 2

Frequency Domain Denoising (FFT Notch + Hiss Filter)

🔧 Surgical Spectral Cancellation
1
FFT → Complex Spectrum
Transform signal into discrete frequency bins: X[k] = np.fft.rfft(x).
2
Hum Notch Filter (60, 120, 180 Hz)
Set bins within ±3 Hz of power-line interference frequencies to zero: X[|f - f0| < 3] = 0.
3
Hiss Attenuation (>4000 Hz)
Scale high-frequency noise bins down by 0.15× to silence broadband microphone hiss.
4
IFFT → Clean Audio
Reconstruct clean time-domain waveform using Inverse FFT: y[n] = np.fft.irfft(X).

📈 Frequency Spectrum & Notch Cancellation

■ 60Hz Power Hum ■ 120/180Hz Harmonics ■ >4kHz Hiss Zone ■ Preserved Speech/Music
def freq_domain_denoise(x, fs, notch_freqs=(60,120,180)): X = np.fft.rfft(x) freqs = np.fft.rfftfreq(len(x), d=1/fs) for f0 in notch_freqs: X[np.abs(freqs - f0) < 3] = 0 X[freqs > 4000] *= 0.15 return np.fft.irfft(X)

Noise Remover · Method 3

Spectral Subtraction (STFT Frame-by-Frame)

🔧 Short-Time Fourier Transform Execution
1
STFT Windowing (512 samples, 50% overlap)
Produces a 2D time-frequency matrix Zxx(f, t) split into Magnitude and Phase.
2
Noise Floor Estimation
First 10 frames are assumed speech-free background noise → compute |N̂(f)|².
3
Power Subtraction with Spectral Floor
Subtract: |Ŝ|² = max(|X|² - α|N̂|², β|N̂|²) with α=2.0 and β=0.02.
4
ISTFT Overlap-Add Synthesis
Combine cleaned magnitude with original phase: Z_clean = |Ŝ| · e^{j∠X} and invert.

Noise Remover · Method 4

Wiener Filter (Optimal MMSE Estimation)

🔧 Adaptive Ratio Multiplication
1
Local Signal-to-Noise Ratio (SNR)
Computes ratio of estimated noise power to total frame power: N(f) / S(f, t).
2
Continuous Adaptive Gain G(f, t)
G = max(1 - |N|² / |X|², 0). Seamlessly ranges between 0.0 (noise) and 1.0 (clean speech).
3
Minimum Mean Squared Error (MMSE)
Mathematically proven to produce minimum distortion among all linear estimators.
⚡ Spectral Subtraction vs Wiener:
• Spectral Subtraction subtracts energy, requiring an artificial floor β to mask clicks.
• Wiener Filter multiplies by smooth gain G, self-adapting naturally across every bin.

📉 Wiener Adaptive Gain Curve

G ≈ 1.0 (Keep Signal) G ≈ 0.0 (Suppress Noise)
gain = np.maximum(1.0 - noise_power / (signal_power + 1e-10), 0.0) clean_mag = mag * gain

Noise Remover · Deep Dive 1

Spectral Subtraction: Over-Subtraction (α) & Floor (β)

⚡ Overcoming "Musical Noise"
1
The Musical Noise Artifact
Direct subtraction |X|² − |N|² creates isolated random peaks in the residual spectrum. In time-domain, these sound like unnatural metallic tones or fluttering bird chirps.
2
Over-subtraction Factor (α = 2.0)
Forces subtraction deeper than average noise: |Ŝ|² = |X|² − α·|N̂|². Completely suppresses residual noise peaks between speech formants.
3
Spectral Floor (β = 0.02)
Prevents bins from dropping to zero: max(..., β·|N̂|²). Leaves an imperceptible, steady ambient wash that psychoacoustically masks tonal distortion.
|Ŝ(f,t)|² = max( |X(f,t)|² − α·|N̂(f)|² , β·|N̂(f)|² )

Noise Remover · Deep Dive 2

spectral_subtraction_denoise: Code Walkthrough

🪜 4-Stage DSP Architecture
1. STFT Decomposition (512 samples, 50% overlap)
Transforms 1D signal into complex matrix Zxx(f, t). Extracts magnitude mag = |Zxx| and phase phase = ∠Zxx.
2. Initial Frame Noise PSD Profiling
Averages the first noise_frames=10 silence frames across time to estimate noise_power(f).
3. Subtraction & Floor Clipping
Executes np.maximum(mag² − α·noise_power, β·noise_power), then takes square root for magnitude.
4. Phase Preservation & ISTFT Synthesis
Multiplies cleaned magnitude with original phase clean_mag · e^{j·phase} and applies Inverse STFT.
🐍 Python DSP Implementation (logic/noise_remover.py)
def spectral_subtraction_denoise(x, fs=FS, noise_frames=10, alpha=2.0, beta=0.02): nperseg, noverlap = 512, 256 f, t, Zxx = signal.stft(x, fs=fs, nperseg=nperseg, noverlap=noverlap) mag, phase = np.abs(Zxx), np.angle(Zxx) # 1. Estimate noise power from initial silence frames noise_power = np.mean(mag[:, :noise_frames] ** 2, axis=1, keepdims=True) # 2. Spectral subtraction with over-subtraction & spectral floor clean_power = mag ** 2 - alpha * noise_power clean_power = np.maximum(clean_power, beta * noise_power) clean_mag = np.sqrt(clean_power) # 3. Polar reconstruction with original phase & ISTFT clean_Zxx = clean_mag * np.exp(1j * phase) _, clean_signal = signal.istft(clean_Zxx, fs=fs, nperseg=nperseg, noverlap=noverlap) return clean_signal[:len(x)]

Noise Remover · Deep Dive 3

Wiener Filter: MMSE Optimal Estimation & Gain Curve

📐 Mathematical Foundations of Wiener Denoising
1
Minimum Mean Squared Error (MMSE)
Derives the mathematically optimal linear estimator minimizing E[(ŝ[n] - s[n])²]. Proven superior to heuristic subtraction.
2
Frequency-Dependent Continuous Gain G(f)
Gain is given by G(f) = SNR / (SNR + 1) = max(1 - P_noise / P_signal, 0). Seamlessly ranges from 0.0 to 1.0 without sharp steps.
3
Multiplication vs Subtraction
Spectral subtraction subtracts energy, creating sharp zero-clipped cliffs (musical noise). Wiener multiplies smoothly, naturally preserving acoustic warmth.

def wiener_denoise(x, fs=FS, noise_frames=10): f, t, Zxx = signal.stft(x, fs=fs, nperseg=512, noverlap=256) mag, phase = np.abs(Zxx), np.angle(Zxx) # 1. Noise PSD estimate from initial frames noise_power = np.mean(mag[:, :noise_frames] ** 2, axis=1, keepdims=True) signal_power = mag ** 2 # 2. Continuous MMSE gain matrix G(f, t) gain = np.maximum(1.0 - noise_power / (signal_power + 1e-10), 0.0) # 3. Soft multiplicative attenuation & ISTFT reconstruction clean_mag = mag * gain clean_Zxx = clean_mag * np.exp(1j * phase) _, clean_signal = signal.istft(clean_Zxx, fs=fs, nperseg=512, noverlap=256) return clean_signal[:len(x)]

Join (Concatenation & Peak Normalization)

📌 Preventing Boundary Clipping

Takes arbitrary clip sequences join(*arrays), validates non-empty segments, and stitches them with np.concatenate(valid). The combined result is passed through normalize() to ensure maximum amplitude stays within [-1.0, 1.0].

def join(*arrays): valid = [a for a in arrays if a is not None and len(a) > 0] return normalize(np.concatenate(valid))

Audio Editor · Feature 3 of 7

Reverse (Time Inversion: y[n] = x[N - 1 - n])

📌 Phase Inversion with Unchanged Magnitude

Time reversal mirrors the audio waveform across the temporal midpoint. In the frequency domain, this inverts the phase angle: ∠Y(f) = -∠X(f), while the magnitude spectrum |Y(f)| = |X(f)| remains 100% identical.

Audio Editor · Feature 4 of 7

Time Scale (Overlap-Add / OLA Pitch-Preserving Speed Change)

📌 Pitch Preservation via Overlap-Add

Naively re-sampling audio changes vocal pitch (chipmunk effect). ReSonus decomposes audio into 30ms Hann-windowed overlapping frames, reads with fixed input hop hop_in, but overlaps synthesis frames at variable distance hop_out = hop_in / speed, then normalizes by window sum.

for i in range(n_frames): frame = x[i*hop_in : i*hop_in + frame_len] * window output[i*hop_out : i*hop_out + frame_len] += frame win_sum[i*hop_out : i*hop_out + frame_len] += window output /= win_sum

Equalizer · Architecture 3 of 3

FIR Windowed-Sinc Bands: Strictly Linear Phase

✨ Why Linear Phase Matters in Studio Mastering

Standard IIR biquad equalizers introduce non-uniform phase delays: different frequency components are delayed by different amounts. This causes transient smearing — drum kicks lose punch and acoustic guitars lose snap.

IIR Biquad Phase Distortion
Non-linear phase response shifts high and low frequencies relative to each other, dispersing sharp transient attacks into bloated waveforms.
FIR Strict Phase Linearity (Constant Group Delay)
Because impulse response is symmetric (h[n] = h[N - 1 - n]), every frequency is delayed by exactly τ_g = (N - 1) / 2 samples. Zero waveform distortion!

detect_tone_freq: Automated FFT Carrier Peak Search

🔍 Adaptive Carrier Acquisition

Incoming Morse transmissions may use any pitch from 400 Hz to 1500 Hz depending on the radio operator's preference. Rather than demanding manual tuning, ReSonus executes a fast full-signal FFT and restricts the peak search to [200, 2000] Hz:

def detect_tone_freq(audio, fs=FS): freqs = np.fft.rfftfreq(len(audio), d=1/fs) mag = np.abs(np.fft.rfft(audio)) mask = (freqs >= 200) & (freqs <= 2000) return freqs[mask][np.argmax(mag[mask])]

match_template: Cross-Correlation Matched Filtering

📐 Sliding Dot Product Theory

Slides template y[n] across recording x[n]: r_xy[k] = ∑ x[n] y[n + k]. Where the sound occurs, samples align in phase and magnitude, producing a prominent correlation spike that identifies the exact millisecond offset:

def match_template(recording, template): corr = signal.correlate(recording, template, mode='valid') best_idx = np.argmax(corr) confidence = corr[best_idx] / (norm(recording[best_idx:best_idx+len(template)]) * norm(template)) return best_idx, confidence
